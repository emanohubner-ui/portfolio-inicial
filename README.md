# Portfolio Inicial

## Project Documentation

### Requirements
- Node.js (version >= 14)
- npm (version >= 6)

### Project Structure
```
portfolio-inicial/
├── src/
│   ├── components/
│   ├── styles/
│   ├── index.js
├── public/
│   ├── index.html
├── package.json
└── README.md
```

### How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/emanohubner-ui/portfolio-inicial.git
   cd portfolio-inicial
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
4. Open your browser and go to `http://localhost:3000` to see the project in action.

### Customization Instructions
- To customize the styles, modify the files in the `src/styles/` directory.
- To add new components, create them in the `src/components/` folder and import them into `src/index.js`.

For more detailed documentation, refer to the project's wiki or contact the maintainer.
